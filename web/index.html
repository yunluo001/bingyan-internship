        配置方案

          外观

          页面没能正常启动

          web/ 只是静态页面。浏览器不允许网页跨域直连 B 站，所以 /api、/live、/passport、/ws 这几个请求需要先跑一个本地转发服务。在 项目根目录 下执行任意一条： 

          node tools/dev-server.mjs --web web            # 不需要 Go
cd server && go run . -addr 127.0.0.1:8787 -web ../web

          然后打开 http://127.0.0.1:8787。不要直接双击 index.html，也不要用 Live Server 这类纯静态服务器。

          想先不联网看效果：node tools/dev-server.mjs --mock， 它会用假房间和本地弹幕把整条链路跑起来。
