# Features

## P0

| 功能 | 说明 | 做到什么算完成 |
| --- | --- | --- |
| 页面骨架 | 抽奖页 + 设置页，两个视图能来回切 | 页面上有账号、参与人数、开始/停止按钮、中奖名单；设置页能打开和关闭 |
| 请求封装 | 统一发请求的入口 | 能带 Cookie、能解析 JSON、B 站返回 `code !== 0` 时把 `message` 抛出来 |
| Cookie 登录 | 粘贴 Cookie，调 `/api/x/space/myinfo` 验证 | 登录成功显示昵称与头像；Cookie 无效时给出明确提示 |
| 扫码登录 | 申请二维码 → 轮询状态 → 拿 Cookie | 二维码能显示；扫完自动登录；过期能重新申请 |
| 房间号解析 | 输入房间号或直播间链接 | 两种输入都能得到数字房间号；非法输入返回空 |
| 弹幕接入 | 取弹幕配置 → 连 WebSocket → 解帧 → 解压 → 收 `DANMU_MSG` | 浏览器控制台能看到直播间实时弹幕 |
| 参与池 | 关键词过滤 + 按 uid 去重 | 关键词为空时所有人都算参与；同一个人反复发只算一次；页面人数实时更新 |
| 抽奖 | 从参与池里随机抽 N 人 | 点开始后按钮变停止；停止时抽出 N 人并展示名单 |

## P1

| 功能 | 说明 |
| --- | --- |
| 多套配置 | 关键词、中奖人数、监控房间各存一套，能新建 / 切换 / 改名 / 删除 |
| 抽奖历史 | 每次开奖自动记一条，能看到关键词、人数、时间、完整名单，能单条删除和全部清空 |
| 导出 Markdown | 把一条历史导出成 `.md` 文件下载下来 |
| 自定义背景图 | 选一张本地图片做页面背景，刷新后还在 |
| 主题切换 | 至少日间 / 夜间两套，用 CSS 变量实现，选择要记住 |

## P2

| 功能 | 说明 |
| --- | --- |
| 中英切换 | 界面文案支持中英两种语言 |
| 多房间 | 同时监听多个直播间，参与者合并进同一个池子 |
| 断线重连 | WebSocket 断开后按 1s / 2s / 4s … 退避重连，能手动停止 |
| 长名单 | 中奖人数很多时，名单卡片内部滚动，页面整体不跟着变长 |

## 验收

找一个正在直播的房间，关键词设成能刷起来的口令（比如「抽奖」）：

1. 登录，加房间，点开始
2. 弹幕带关键词时人数涨；同一个人重复发不重复计数
3. 点停止，名单人数对，没有重复人
4. 刷新后配置和历史还在
